1. Introduction to Agentic AI

Objective

The primary objective of this project is to research, architect, and implement an autonomous, multi-agent artificial intelligence system engineered to address real-world challenges in personal financial tracking and budget planning. By transitioning from passive generative text completion to an active, goal-driven Agentic AI framework, the system models complex financial workflows into distinct, specialized agents that interact through state persistence, reasoning loops, deterministic financial logic, and machine learning models without requiring constant human intervention.

Key Concepts Understood

  • Perception-Reasoning-Action Loop: Autonomous agents observe external transaction streams, reason through multi-step analytical pathways, and execute deterministic calculations and API operations to reach a defined goal.
  • Stateful Graph Orchestration (LangGraph): Orchestrating agent workflows as cyclic, state-preserving directed graphs where nodes represent domain agents and edges enforce conditional logic and verified state transitions.
  • Multi-Agent Systems (MAS): Decomposing monolithic tasks into modular agents (Categorization, Analytics, Anomaly Detection, Budgeting, Reporting) collaborating over a unified state schema.
  • Hybrid Intelligence Integration: Combining symbolic heuristics, machine learning algorithms (unsupervised outlier detection), and Large Language Models (LLMs) to ensure mathematical precision and high contextual accuracy.
  • Operational Guardrails & Grounding: Enforcing mathematical cash flow constraints and budget guardrails to prevent unviable financial planning while maintaining autonomous analytical reasoning.

2. Understanding of Agentic AI

What is an AI Agent?

An AI Agent is an autonomous computational entity capable of perceiving its environment, maintaining stateful memory, reasoning over objectives, making independent decisions, and taking actions via tools to accomplish specific goals with minimal human supervision. Unlike traditional static programs that strictly follow predefined if-else rules, or standard stateless LLM prompts that simply return passive text, an Agentic AI system actively executes multi-step plans, invokes specialized software tools, evaluates intermediate outcomes, and autonomously adapts its workflow.

In the context of personal finance, an agentic framework is essential. Traditional rule-based software fails to handle unstandardized merchant descriptions, obscure transaction codes, or dynamic budget adjustments, while basic chatbots lack deterministic mathematical integrity. An Agentic AI architecture bridges this gap by delegating specialized financial tasks to autonomous agents that collaborate to ensure precision, reliability, and proactive user guidance.

4. Problem Statement

Problem Statement

Managing personal expenses manually is time-consuming, tedious, and prone to significant human error. Individuals consistently face critical challenges in maintaining financial health: struggling to categorize diverse transactions, failing to identify discretionary overspending habits, missing billing anomalies or duplicate subscription charges, and lacking a structured mechanism to enforce sustainable daily and monthly budgets.

Existing expense tracking tools primarily serve as passive digital recording ledgers. They display retrospective summary charts but lack autonomous analytical reasoning, anomaly flagging, and personalized forward-looking recommendations. Consequently, there is a clear necessity for an Agentic AI-Based Intelligent Expense Analysis and Budget Planner that autonomously ingests financial data, identifies spending patterns, detects duplicate and unusual charges, flags budget deficits in real time, and formulates actionable financial strategies.

5. Proposed Solution

Project Title

Title: Agentic AI-Based Intelligent Expense Analysis and Budget Planner

Project Description

The proposed solution is an autonomous, multi-agent financial management platform architected using LangGraph, Python, and modern web microservices. The system coordinates five specialized AI agents operating sequentially over a shared state graph to deliver complete end-to-end expense management:

1. Transaction Categorization Agent: Autonomously standardizes ambiguous merchant descriptions and classifies expenses into standardized categories (Food, Groceries, Shopping, Travel, Bills, Housing, Healthcare, Entertainment).

2. Spending Analysis Agent: Analyzes monthly expenditures, identifies category distribution, calculates month-over-month trends, and isolates unnecessary/discretionary expenses.

3. Anomaly Detection Agent: Flags suspicious expenditures, extreme high-value outliers, and duplicate billing charges with clear, human-understandable explanations and verification guidance.

4. Budget Planning Agent: Dynamically compares planned category limits against income, computes daily spending allowances, enforces savings targets, and flags budget deficits in real time.

5. Report Generation Agent: Generates structured executive briefings, debt-reduction advice, and visual charts (Matplotlib) summarizing monthly spending distribution.

6. Implementation

Technologies Used

  • Programming Language: Python 3.12+ / 3.14
  • LLM / AI Model: Google Gemini API & scikit-learn
  • Agent Framework: LangGraph (StateGraph workflow orchestration)
  • Tools / APIs: Pandas, NumPy, Matplotlib, scikit-learn, Google Generative AI SDK
  • Database / Storage: SQLite with SQLAlchemy ORM
  • Frontend: Streamlit (Reactive Web Dashboard)
  • Backend: FastAPI & Uvicorn (RESTful Backend Services)

Implementation Steps

  • Step 1: State Schema Design (app/agents/state.py): Built a structured state representation encapsulating transactions, user constraints (income, savings targets, category limits), category spending summaries, detected anomalies, recommended budgets, and visual reports.
  • Step 2: Transaction Categorization Agent (app/agents/categorization.py): Implemented semantic classification and pattern normalization to classify raw transaction records into standard household expense buckets.
  • Step 3: Spending Analysis Agent (app/agents/spending_analysis.py): Engineered analytics routines to compute category-wise totals, month-over-month trajectories, and highlight non-essential discretionary items.
  • Step 4: Anomaly Detection Agent (app/agents/anomaly_detection.py): Developed an anomaly detection engine detecting duplicate charges, extreme outliers (top 5% spend), and sudden spikes, paired with plain-English contextual explanations and recommended verification steps.
  • Step 5: Budget Planning Agent (app/agents/budget_planning.py): Formulated mathematical budget logic calculating planned net cash flow (Income - Limits), daily budget allowance ((Income - Savings) / Days), and real-time deficit alerts when user limits exceed income.
  • Step 6: Report Generation Agent (app/agents/report_generation.py): Integrated Google Gemini LLM API to produce executive summaries and actionable financial strategies, coupled with automated Matplotlib chart rendering.
  • Step 7: Graph Assembly & Compilation (app/agents/graph.py): Assembled and compiled the sequential LangGraph pipeline connecting all five agents with strict state propagation.
  • Step 8: Application & Dashboard Layer (dashboard/streamlit_app.py): Developed a FastAPI backend exposing ingestion, analysis, and report endpoints, paired with an interactive Streamlit UI featuring live KPI cards, daily budget tracking, and instant deficit warnings.

Demonstration

The application was demonstrated through real-time interactive testing and evaluation across core operational scenarios:
